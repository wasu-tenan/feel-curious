A small program that writes one short text to intrigue the AI judge reading
it: a concrete mystery, an open loop, a detail that doesn't quite add up.

## Run

```sh
python3 main.py
```

This writes the text to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`,
or the path given with `--output`). Python 3.13, standard library only,
deterministic — every run writes the same text.
